## 项目背景

这个网站用于集中展示个人简历、项目作品、学习记录和生活记录。目标是保持内容结构清晰，同时避免引入数据库和服务器运维。

## 当前方案

- 使用 Astro 生成静态页面
- 使用 Content Collections 管理结构化内容
- 使用 Pagefind 提供全站搜索
- 使用 Cloudflare Pages 与自定义域名部署

## 下一步

替换个人资料，补充真实项目与简历内容，并配置正式域名和统计服务。
